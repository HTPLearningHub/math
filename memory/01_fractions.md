## Terms defined here (do not define them again anywhere else)

dividend, divisor, quotient, fraction, numerator, denominator, proper fraction,
improper fraction, mixed number, equivalent fractions, simplify (reduce), remainder.

Also introduced here: the symbols $\div$, $<$ and $>$, and the reading of $\frac{a}{b}$.

## Formulas that live here

* $a \div b = \frac{a}{b}$ (§ 2.2)
* $\frac{a}{b} = \frac{a \times c}{b \times c} = \frac{a \div c}{b \div c}$ (§ 3.2)
* $\frac{N}{D} = W\frac{R}{D}$ with $N = (W \times D) + R$ (§ 5.3)
* $W\frac{N}{D} = \frac{(W \times D) + N}{D}$ (§ 5.4)

## Corrections made to the source

* The source defined a fraction as "a value between 0 and 1". That is only true for **proper**
  fractions. The book defines a fraction as a number of equal parts of one whole, and puts the
  "between 0 and 1" statement in § 2.4, where proper fractions are defined.
