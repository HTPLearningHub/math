# Mathematics from the beginning

This repository **is** the book. One author, one reader, one path: from the first idea to
advanced topics.

## How to read it

* Read the chapters in order. Each one uses what came before it.
* Every idea is explained **once**, in the chapter where you first need it. Later chapters
  link back instead of repeating.
* Every formula comes with a plain-English sentence, a small example with real numbers, and
  a list that explains each symbol.
* Every picture is there to be looked at. Read the caption under it before you go on.
* At the end of each chapter there are questions with hidden answers. Try them before you
  open the answer.

## Labels used in the chapters

| Label | Meaning |
| --- | --- |
| **Definition** | A technical term explained in simple English. |
| **Explanation** | A deeper description of how or why something works. |
| **Example** | A concrete case. |
| **Note** | An important detail that is easy to miss. |
| **Warning** | A common mistake or a risk. |
